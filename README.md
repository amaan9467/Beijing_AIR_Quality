## 🌏 Beijing Air Quality Analysis Dashboard (2004–2005) — Power BI Project

I'm excited to showcase my latest **data visualization project** where I analyzed **Beijing’s air quality** between 2004 and 2005 using **Power BI**. This project involved end-to-end data analysis and dashboard development to uncover key environmental insights.

### 🔍 Project Highlights:

- ✅ **Cleaned and modeled** raw air pollution datasets for accurate reporting and analysis.  
- ✅ **Visualized key metrics** like NO₂, CO, SO₂, humidity, and rare compounds using **line charts**, **card visuals**, and **donut graphs**.  
- ✅ **Built dynamic slicers and filters** for real-time pollutant breakdown and date-based insights.  
- ✅ Leveraged **DAX** functions for time intelligence, including identifying **most humid and hottest days**.  
- ✅ Designed a **user-friendly and interactive dashboard** for stakeholders to quickly understand environmental patterns and support decision-making.

### ⚙️ Tools & Technologies Used:

- Power BI  
- DAX  
- SQL  
- Python
